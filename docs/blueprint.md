# **App Name**: PyGenius

## Core Features:

- File Type Selection: Select the file type to be generated (api.py, schema.py, logic.py).
- Section Generation (Header, Middle, Footer): Allows for creation of python file by providing distinct sections
- AI-Powered Section Generation: Use AI to generate code for the header, middle, or footer section based on provided inputs and context. The LLM uses the information to provide helpful functionality.
- AI-Powered Complete File Generation: Use AI to generate the entire file (header, middle, and footer) based on a single prompt.
- Context-Aware AI Section Filling: The AI analyzes the filled sections of a file and generates content for the empty sections accordingly.
- AI-Powered Code Fixing: Use AI to identify and fix errors or improve the quality of the generated code. Input an optional context for personalized fixing.
- Personalized File Generation: Allow users to input personalized prompts and context for each section to tailor the generated code to their specific needs.

## Style Guidelines:

- Primary color: A vibrant teal (#008080) to reflect the tech aspect of the application.
- Background color: A desaturated light teal (#E0F8F8) for a clean interface.
- Accent color: A light cyan (#7FFFD4) to add highlights and vibrancy to key UI elements.
- Font: 'Inter' sans-serif font for the body, a grotesque style with a modern, neutral, and clean feel, appropriate for large amounts of text
- Font: 'Space Grotesk' for headlines, a proportional sans-serif with a computerized feel; in combination with the Inter body font, adds contrast in the design.
- Use minimalistic and clear icons for file types and actions.
- A clean and structured layout to facilitate easy code generation.
- Subtle animations to enhance the user experience during the generation process.
